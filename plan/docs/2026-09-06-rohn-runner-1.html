1. Supabase Pagination (1,000 Rows Cap)

แก้ปัญหาข้อจำกัด 1,000 แถวของ PostgREST ด้วยการใช้ Loop ดึงข้อมูลแบบ .range(from, to) ต่อเนื่องจนครบทุกรายการ ทำให้รองรับงานวิ่งขนาดใหญ่ได้ 100%

2. Realtime Broadcast & Focus Refetch

สมัครรับข้อมูลผ่าน supabase.channel('results:...') พร้อม Fallback ด้วย Event focus เพื่อดึงข้อมูลสดทันทีเมื่อผู้ใช้คลิกสลับแท็บกลับมา

3. ไทม์ไลน์ Race Splits จริง

ฟังก์ชัน checkpointTimeline คำนวณเวลาตั้งแต่ Check-in, เวลา Gun Start ทางการ, สเตชั่น CP ทุกจุด จนถึงเวลาเข้าเส้นชัย Finish Line

4. Cross-Window Monitor Casting

รองรับการรับข้อมูลนักวิ่งข้าม Browser Tabs/Windows ผ่านทั้ง BroadcastChannel, window.postMessage และ localStorage
